# 文字计算：设计理念

## 一、出发点

- 文字首先是被用来"说服"的，其次才是用来"陈述事实"的。
- 说服一个人，往往只需要文字看起来有逻辑：因果词、权威引用、情绪节奏、绝对化断言，都可以让一段话显得不可反驳。
- 常识有时候是错的：常识是多数人经验的压缩归纳，样本可能偏差、可能过时、可能从未被严格检验。
- 小众观点有时候是对的：一个观点对不对，不取决于信它的人数，取决于证据是否充分、推理是否成立。
- 结论：判断一句话，不能只看"信息来源是否主流"，要看它的推理结构、前提可检验性、结论是否被真正支撑。

## 二、工具立场

解字（Unfold）只做三件事：

1. **拆结构**：把一段话拆成一条条主张单元，再拆出前提与结论；
2. **查推理**：检验从前提推出结论的过程是否有效、是否自洽、用了什么手法；
3. **标来源**：给每条主张标注素材来源与可检验性，但标签不参与真伪判定。

解字明确不做：

- 不做外部事实核查，不去查证客观世界的真假；
- 不评价说话人的人品、智商、动机；
- 不因为"来源小众"而偏向谁，也不因为"来源主流"而轻信谁。

## 三、为什么用逻辑

- 逻辑是唯一与立场无关的裁判：前提真假是经验问题（交给现实检验），推理形式对不对是逻辑问题（交给规则检验）。
- 形式有效 ≠ 现实正确：前提全真 + 形式有效，结论才必然为真（可靠论证）。
- 一篇文章的迷惑性通常来自六种手法，对应解字的六种推导判定：
  1. 偷换概念（修改词语定义）；
  2. 隐瞒不利事实（只讲支持自己的例子）；
  3. 夸大前提适用范围（个案当普遍）；
  4. 循环论证（前提里已经藏着结论）；
  5. 逻辑断裂（前提与结论根本接不上）；
  6. 修辞与情绪代替论证（排比、煽情、权威包装）。
- 拆解 = 把上述手法显性化，让读者看到"这段话是靠逻辑还是靠话术撑起来的"。

## 四、判断信息来源的意义

- 来源标签是阅读参考，不是真值裁决：标为"互联网流传"不等于错，标为"教科书通识"不等于对。
- 来源标签的真正用途是给出**可检验性提示**：这条说法，现实有没有可能验证它？
- 可检验性梯度（从不可检验到已检验）：同义反复 → 原则上不可证伪 → 理论可证实但现实难取证 → 可检验但未检验 → 教科书通识 → 有数据支撑的已检验结论。
- 读者应当把"来源可疑"当作"该去查证"的信号，把"逻辑断裂"当作"别被带走"的信号。

## 五、一句话总结

解字不告诉你"这句话是不是真的"，解字告诉你"这句话是怎么推出来的、推得对不对、值不值得信"——把决定权交还给现实检验和读者自己。
