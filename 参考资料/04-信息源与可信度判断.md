# 信息源与可信度判断（解字参考资料 04）

> 本文件对应设计理念中的核心关切：**判断一句话的信息来源**——常识有时候是错的，小众观点有时候是对的，来源不能决定对错。

## 1. 与设计理念的关系

- **常识有时候是错的**：常识是"多数人经验的压缩归纳"，样本可能是幸存者、可能是过时知识、可能从未被严格检验；
- **小众观点有时候是对的**：观点的对错不取决于人数，取决于证据是否充分、推理是否成立；
- **因此**：来源只能说明"说法从哪来"，不能决定"说法对不对"；
- **解字的态度**：标签来源、标注可检验性、检验推理，但绝不以"来源主流 / 小众"定真伪。

## 2. 判断一句话信息来源的线索

**词汇线索：**

| 线索 | 倾向判断 |
| --- | --- |
| 绝对化词：一定、必然、绝对、从不、永远 | 全称断言 / 个人断言（需重点检验） |
| 模糊词：据说、有人说、网上说、听说、研究表明（无出处） | 互联网流传 / 不可溯源 |
| 术语规范、表述稳定、无情绪词 | 教科书通识知识 |
| 第一人称评价：我觉得、我认为、依我看 | 个人原创断言 |
| 换词重复：A 就是 A | 同义反复废话 |
| 事后可解释：总能圆回来 | 原则上不可证伪 |

**声称结构：**

- 有无具体出处（书名、论文、人名、数据来源、链接）；
- 无出处 + 耸动表达 + 夸张数字 → 互联网流传；
- 有出处但出处本身不可查 → 来源存疑，按个人原创处理并备注。

**可检验性：** 能否设计观测去验证（见参考资料 01 第 8 节）。

**注意：** 以上线索只能推断"文本表现"，不能确证作者真实读过什么。

## 3. 可检验性梯度（从不可检验到已检验）

| 层级 | 类型 | 含义 | 读者用法 |
| --- | --- | --- | --- |
| 1 | 同义反复 | 永真废话，无信息量 | 忽略其信息价值，只看它是否被用来"充数" |
| 2 | 原则上不可证伪 | 无观测能推翻 | 讨论真伪无意义，只拆结构 |
| 3 | 理论可证实、现实难取证 | 原理可检验但证据拿不到 | 当作"有待证据"的主张 |
| 4 | 可检验但未检验 | 有验证路径但没人验证过 | 当作"假设"，别当结论 |
| 5 | 教科书通识 | 学科共同体反复检验过的知识 | 可信度较高，但仍可被更新 |
| 6 | 已检验且有数据支撑 | 有明确观测证据 | 最接近"可当依据"，仍要查数据质量 |

**用途：** 梯度给读者一个"该拿它当什么用"的参考，不参与真假裁决（第六步报告提示中体现）。

## 4. 常见误导结构（文字迷惑性清单）

| 结构 | 表现 | 解字对应 |
| --- | --- | --- |
| 逻辑成立但前提假 | 形式有效，前提是编的/夸大的 | 第五步"现实必要条件"未满足 |
| 前提真但推理断 | 相关性与充分性不足 | 第五步"逻辑断裂" |
| 修辞代替论证 | 排比、煽情、夸张数字 | 第二步形态定性"修辞抒情渲染" |
| 权威包装 | "专家说""研究表明"（无出处） | 第三步来源标签 + 谬误 2（诉诸权威不当） |
| 情绪杠杆 | 恐惧、愤怒、同情转移注意力 | 谬误 4（诉诸情感） |
| 定义漂移 | 换个含义继续推 | 谬误 13（偷换概念） |
| 沉默的例外 | 只讲支持自己的例子 | 谬误 17（忽略反例） |

## 5. 使用守则

- 本工具输出：结构拆解 + 推理检验 + 来源标签 + 可检验性标注；
- 本工具不输出：对客观事实真假的最终裁决（现实检验交给读者和证据）；
- 读者用法：
  - "来源可疑" → 该去查证的信号；
  - "逻辑断裂" → 别被带走的信号；
  - "内部自洽" → 只说明形式成立，仍需查前提真伪；
  - "来源小众" → 不等于错，查证据；"来源主流" → 不等于对，查推理。
