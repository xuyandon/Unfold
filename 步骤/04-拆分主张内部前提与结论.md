# 第四步：拆分每一条主张内部的前提与结论

> 对应 SKILL.md 运行流程表第 4 条。在第三步切片完成后，逐条处理每一个主张单元。
> 本步产出每条主张的"完整前提集合"，是第五步检验的直接输入。

## 本步目标

1. 逐条处理主张单元，拆出**句内的前提片段**与**结论**；
2. 区分"原文写明"与"工具推断"的因果结构；
3. 补全**隐含前提**（论证重构）；
4. 识别该主张的**推理模式**。

---

## 4.1 显性因果连接词检索

先查原文有没有显性因果/推导连接词：

| 类别 | 连接词 |
| --- | --- |
| 因果 | 因为、所以、因此、故、于是、从而、导致、使得、由于、鉴于 |
| 推导 | 由此可见、可见、足以、说明、表明、证明、意味着、归结起来 |
| 条件 | 如果…那么、只要…就、只有…才、除非…否则、一旦…就 |
| 让步转折 | 虽然…但是、尽管…然而（转折常隐藏前提，需要补全） |
| 推断 | 既然…就、照这么说、按这个道理 |

**处理规则：**

- 有显性连接词 → 直接从原文摘出"前提片段"与"结论文本"，注明**原文写明**；
- 无显性连接词 → 由工具推断出前提-结论结构，**必须备注"原文未写明，系工具推断"**；
- 一个主张可有多个前提片段（"……，而且……，所以……"）。

## 4.2 句内结构抽取规则

- **前提片段**：承担依据功能的从句或短语；
- **结论**：被推出的主句；
- 示例：
  - "因为下雨，所以比赛取消" → 前提片段"下雨"；结论"比赛取消"；
  - "只有坚持练习，才能拿冠军" → 必要条件句：形式化为"拿冠军 → 坚持练习"，即"拿冠军"以"坚持练习"为前提；
  - "他是留学生，外语一定很好" → 句内前提"他是留学生"；结论"外语一定很好"（隐含前提见 4.3）；
  - "今天真累" → 纯断言，句内无前提，记为"无句内前提"。

## 4.3 补全隐含前提（论证重构）

- 若仅凭"句内前提片段 + 外部依赖"推不出结论，说明推导中藏着**没写出来的前提**；
- **补全原则：**
  1. 补"最少的、必要的"前提，不脑补作者没依赖的东西；
  2. 忠实于文本倾向，不替作者升级主张；
  3. 补全的前提必须标注为"隐含前提（工具补全）"，与原文明示内容严格区分。
- 示例："他是留学生，外语一定很好。"
  - 句内前提：他是留学生；
  - 结论：外语一定很好；
  - 隐含前提：留学生外语都很好（全称）——补全后该推导才可检验（第五步会查这个全称前提是否成立）。
- 若连"最小必要前提"都补不出来，说明该处存在逻辑断裂，如实记录，不硬补。

## 4.4 完整前提集合

每条主张的**完整前提集合** =

1. 本句内部的前提片段；
2. 所依赖的前文主张（第三步的依赖记录）；
3. 补全的隐含前提（若需要）。

**用途：** 第五步用这个完整集合检验推导全过程。缺了哪一块，推理链就断在哪。

## 4.5 推理模式识别（逻辑学衔接）

识别该主张使用的推理模式（供第五步检验引用，规则详见 `参考资料/01-形式逻辑基础.md`）：

| 模式 | 形式 | 有效性 |
| --- | --- | --- |
| 肯定前件 | P→Q，P ⊢ Q | 有效 |
| 否定后件 | P→Q，¬Q ⊢ ¬P | 有效 |
| 否定前件 | P→Q，¬P ⊢ ¬Q | 无效（形式谬误） |
| 肯定后件 | P→Q，Q ⊢ P | 无效（形式谬误） |
| 假言三段论 | P→Q，Q→R ⊢ P→R | 有效 |
| 选言三段论 | P∨Q，¬P ⊢ Q | 有效 |
| 联言分解 | P∧Q ⊢ P | 有效 |
| 二难推理 | P→R，Q→R，P∨Q ⊢ R | 有效（构造性） |
| 归谬法 | 假设 ¬C，推出矛盾 ⊢ C | 有效 |
| 直言三段论 | 所有 M 是 P，所有 S 是 M ⊢ 所有 S 是 P | 有效（需格检验） |
| 枚举归纳 | 多个例子 ⊢ 一般结论 | 强度问题，非有效性问题 |
| 穆勒因果法 | 求同 / 求异 / 共变 / 剩余 / 求同求异并用 | 因果推断，查对照是否齐全 |
| 类比推理 | A≈B，A 有 P ⊢ B 有 P | 强度取决于相似性是否相关 |
| 权威论证 | 专家 E 说 P ⊢ P | 查 E 是否真权威、是否在其领域内、专家间是否一致 |
| 统计论证 | 样本 X% ⊢ 总体 X% | 查样本代表性、随机性、基数 |

## 4.6 输出格式

```
U__
- 原文：____
- 显性因果词：有（____）/ 无
- 句内前提片段：____ / 无
- 结论文本：____ / 纯断言无结论
- 因果结构来源：原文写明 / 工具推断（备注：原文未写明该因果结构）
- 外部依赖：U__（见第三步）/ 空
- 补全的隐含前提：____（工具补全）/ 无
- 推理模式：____
- 完整前提集合：
  P1（句内）：____
  P2（依赖）：____
  P3（隐含）：____
  结论 C：____
```

## 与逻辑学的衔接

- 隐含前提补全对应 `参考资料/02-论证重构与评估模型.md` 第 1、2 节（标准式重构、省略三段论）；
- 显性连接词 → 推理模式的映射，是"原文写明 vs 工具推断"分界的操作基础；
- 必要条件句（只有…才）的形式化是常见错误点：许多人把必要条件当充分条件用，第四步必须正确形式化，第五步才能查出来。
