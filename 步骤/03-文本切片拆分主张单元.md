# 第三步：文本切片，拆分主张单元

> 对应 SKILL.md 运行流程表第 3 条。在第二步定性后执行。
> 本步把长文本切成一条条独立的主张单元，为每条标注素材来源与依赖关系，并做命题形式化标注。

## 本步目标

1. 把整篇文本切成**主张单元**（每条 = 一个完整判断或断言）；
2. 给每条主张打**素材来源标签**（只按文字表现推断）；
3. 记录每条主张的**依赖关系**（是否把前文主张当作前提）；
4. 顺手做**命题形式化标注**，供第五步检验使用。

---

## 3.1 什么是"主张单元"

- 一条完整的判断或断言：有明确的对象（主语）+ 关于它说了什么（谓语）。
- 例："熬夜伤身"是单元；"熬夜"不是；"伤身"不是。
- **切分到"句子级断言"，不切分到单个词语。**

**复合句处理规则：**

| 复合句类型 | 处理 |
| --- | --- |
| 并列复合句（……，而且…… / 不但……还……） | 拆成多个单元 |
| 因果复合句（因为……所以…… / 既然……就……） | 作为一个单元（第四步再从内部拆前提片段与结论） |
| 转折复合句（虽然……但是……） | 通常拆成两个单元（让步事实 + 主断言），并在依赖关系中注明前者支撑后者 |

**编号规则：** 按出现顺序编号 U1、U2、U3……，每条记录原文（逐字摘录）、位置（第几段）。

## 3.2 素材来源标签

给每条主张打一个标签。**按文字表现推断，不代表作者真实阅读经历。**

| 标签 | 含义 | 识别线索 |
| --- | --- | --- |
| 同义反复废话 | 换一种说法重复自己，无信息量 | "A 就是 A"结构："凡是努力的人都不懒""胜利者就是赢的人" |
| 原则上不可证伪 | 任何观测都无法推翻 | 见第一步 1.4 的判定程序与典型形态 |
| 理论可证实、现实难取证 | 原理上能检验，但现实中证据难以获取 | "他当时一定很痛苦""这个策略长期有效"（难以回溯验证） |
| 教科书通识知识 | 主流教材、公认学科知识 | 学科术语规范、表述稳定、无情绪词、无个人色彩 |
| 互联网流传说法 | 网络梗、营销文案、未经证实的传言 | 夸张数字、耸动表达、"据说""网上说""很多人都说" |
| 个人原创断言 | 作者自己的观点、推断、感受 | 第一人称观点、评价性判断、无引用、无出处 |

**规则：**

- 标签只作"阅读参考"，**不参与逻辑真伪判定**（最终报告中必须提示这一点）；
- 拿不准时选"个人原创断言"并在备注写"来源存疑"；
- 一条主张有多个候选标签时，选最贴切的一个，其余写入备注；
- 素材标签与第六步的"不可证伪提示"互相独立：教科书知识也可能被误用，互联网说法也可能正确。

## 3.3 依赖关系记录

- 检查每条主张：它是否**把前面某条（或某几条）主张当作自己的前提**来用？
- 是 → 记录依赖编号（如 U1、U3）；否 → 标记"空"。
- **依赖是"文本明示或明显暗含地以之为据"，不是读者自由联想。**

**示例：**

- "U1：熬夜伤身。U2：所以我不熬夜。" → U2 依赖 U1；
- "U1：他是东北人。U2：东北人都豪爽。U3：所以他豪爽。" → U3 依赖 U1、U2（U2 是中介前提）；
- "U1：今天天气不错。U2：这家店的面很好吃。" → U2 依赖为空（两件事无关，不能强行建立依赖）。

## 3.4 命题形式化标注（逻辑学衔接）

对每条主张顺手标注三项，供第五步检验使用：

1. **命题类型**：
   - 单称命题：这个 S 是 P（"老王迟到了"）；
   - 全称命题：所有 S 都是 P（"所有广告都在骗人"）——线索词：所有、凡是、都、一律、从不；
   - 特称命题：有些 S 是 P（"有的专家不可信"）——线索词：有些、有的、部分、某些、少数、个别；
   - 关系命题：a 与 b 有某关系（"A 优于 B"）。
2. **模态词**：必然（一定、必定）、可能（也许、或许、可能）、应当（应该、必须）、可以。
3. **判断类别**：
   - 事实判断（描述现实：是 / 不是）；
   - 价值判断（评价好坏：该 / 不该、好 / 坏、对 / 错）；
   - 定义判断（约定词义：所谓 X 就是 Y）。

**警惕量词漂移：** 前提写"有些"，结论却用"所有"——这是第五步"夸大适用范围"的典型来源，第三步就要把量词抓出来。

## 3.5 输出格式

```
【主张单元清单】
U1
- 原文：____（逐字摘录）
- 位置：第_段
- 素材来源：____（备注：____）
- 依赖前文主张：空 / U__
- 形式化：单称/全称/特称/关系 + 必然/可能/应当/可以 + 事实/价值/定义
U2
- ……
（按出现顺序编号，直到全文切完）
```

- 命题形式化（全称/特称、模态、量词）是第五步用形式逻辑检验的输入，对应 `参考资料/01-形式逻辑基础.md` 第 2、3 节；
