# 第五步：检验推理链路

> 对应 SKILL.md 运行流程表第 5 条。在第四步产出"完整前提集合"后，逐条检验。
> 本步是核心：判定推导情况、检验内部语境自洽、整理现实必要条件、整理被回避的客观事实。

## 本步目标

用每条主张的完整前提集合，检验从前提推导到结论的全过程，并完成四项分析：

1. 判定**推导情况**（六选一，可叠加）；
2. 检验**内部语境自洽**（假设前提全真，看形式能否推出结论）；
3. 整理**现实必要条件**（前提要符合现实，现实得满足什么）；
4. 整理**被回避的客观事实**（摆出来会削弱论证的事实）。

---

## 5.1 判定推导情况

| 判定 | 含义 | 识别程序 |
| --- | --- | --- |
| 前提齐全、推理合规 | 前提足够，且按有效规则推出结论 | 用完整前提集合按规则试推，能推出且无换词 |
| 依靠修改词语定义得出结论 | 偷换概念 / 模棱两可 | 关键词在前提与结论中含义漂移：同一个词换了意思 |
| 刻意隐瞒客观事实得出结论 | 选择性证据（cherry picking）/ 忽略反例 | 结论的适用范围比前提能支持的更大，且存在明显应提未提的反例 |
| 夸大原有前提的适用范围 | 以偏概全 / 轻率概括 / 特例泛化 | 前提是特称或个案，结论却是全称或大范围 |
| 前提已包含结论，循环废话 | 循环论证 / 丐题 / 同义反复 | 把结论本身（或其等价物）当作前提 |
| 前提全认也推不出结论 | 逻辑断裂（non sequitur） | 用全部前提（含最小补全）仍推不出结论，或结论与前提无关 |

**判定程序（决策树）：**

1. 把所有前提假设为真（内部语境），按形式逻辑规则试推结论；
2. **推得出** → 检查推理过程中有没有偷换概念（关键词含义漂移）：
   - 没有 → 判定"前提齐全、推理合规"；
   - 有 → 判定"依靠修改词语定义得出结论"，记下被偷换的词语及其两个含义；
3. **推不出** → 检查是否只差"结论本身"就能推出：
   - 是 → 判定"前提已包含结论，循环废话"，说明循环路径；
4. 推不出 → 补全最小隐含前提后再试：
   - 能推出 → 检查这个隐含前提是否夸大（前提是小范围、隐含前提却是大范围）：
     - 是 → 判定"夸大原有前提的适用范围"，记下前提范围 vs 结论范围；
     - 否 → 判定"前提齐全、推理合规"（隐含前提如实标注）；
   - 仍推不出、或结论与前提无关 → 判定"逻辑断裂"，说明缺了哪个关键环节；
5. 无论上述哪种，若发现论证**刻意回避了明显相关的反面事实** → 加记"刻意隐瞒客观事实"（可与以上判定叠加，单独列出）。

## 5.2 内部语境自洽检验

- **含义：** 假设所有前提在文本语境里全部为真，单看推理形式，能不能得到结论。
- **做法：** 把结论与前提抽象成 P、Q，用规则/真值表检验（详见 `参考资料/01-形式逻辑基础.md`）。
- **判断结果：** 自洽（形式有效）/ 不自洽（形式无效）。
- **必须提示（写入报告）：** 内部自洽只代表"推理形式有效"，**不等于**前提在现实为真，**不等于**结论现实正确。前提全假时，形式再有效，结论也不可靠。

## 5.3 现实必要条件整理

- **含义：** 整套前提若要符合客观现实，现实世界必须满足哪些条件。
- **做法：** 逐条前提问"现实要满足什么，这条才为真？"

| 前提类型 | 需要检查的现实条件 |
| --- | --- |
| 事实前提 | 现实中需存在对应事实 / 数据 / 可核实来源 |
| 全称前提 | 现实中需无例外，或有明确边界（"所有"很难成立） |
| 特称/样本前提 | 样本需有代表性、数量足够、随机抽取 |
| 定义前提 | 定义需与现实用法一致、未被偷换 |
| 因果前提 | 需排除其他解释：时间先后、共同原因、有无对照 |
| 价值前提 | 需说明评价标准与适用范围（价值无客观真假） |

- 输出：逐条列出"现实必要条件"，未满足的标注"现实中难以满足 / 未证实"。

## 5.4 被回避的客观事实整理

- **含义：** 论述刻意不去提及、一旦摆出会明显削弱论证说服力的事实。
- **做法：**
  1. 看结论的适用范围，找被排除在外却应纳入的反例；
  2. 看前提来源，找与该主张冲突的已知事实；
  3. 看价值判断，找被忽略的后果、代价、副作用；
  4. 看统计论证，找缺失的基数、对照组、时间跨度。
- **规则：**
  - 无此类事实 → 留空，不硬凑；
  - 此项动用模型记忆中的世界知识，但仅用于评估"论证的说服力结构"，**不是**对客观事实的裁决（第六步免责说明会重申）。

## 5.5 输出格式

```
U__
- 推导情况判定：____
  - 若为"修改定义"：被偷换的词语 + 两个含义
  - 若为"隐瞒事实"：被回避的事实清单
  - 若为"夸大适用"：前提范围 vs 结论范围
  - 若为"循环废话"：循环路径说明
  - 若为"逻辑断裂"：缺失的关键环节说明
- 内部语境自洽：自洽 / 不自洽（试推过程简述）
- 现实必要条件：
  R1：____
  R2：____
- 被回避的客观事实：____ / 无
```

## 与逻辑学的衔接

- 六类判定与非形式谬误的映射见 `参考资料/03-非形式谬误清单.md` 第 6 节：
  - 修改词语定义 ↔ 偷换概念、模棱两可、歧义；
  - 隐瞒客观事实 ↔ 样本偏差、忽略反例、选择性证据、基数谬误；
  - 夸大适用范围 ↔ 以偏概全、轻率概括、合成/分解、滑坡、特例泛化；
  - 循环废话 ↔ 循环论证、丐题、同义反复；
  - 逻辑断裂 ↔ 非形式脱节、无关前提、稻草人、转移话题；
- 内部自洽检验用 `参考资料/01` 的演绎规则与三段论格检验；归纳类推理按"强度"评估而非"有效性"；
- 论证评估三标准（可接受性、相关性、充分性）见 `参考资料/02` 第 5 节，与 5.1–5.4 一一对应。
